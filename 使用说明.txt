知识库问答系统 - 使用说明
====================================

【这是什么】
一个本地运行的 AI 知识库问答系统：把文档（PDF / Word / Excel）上传后，
可以直接向它提问，例如"美味居最新租金多少"、"2025年12月水费合计是多少"。
所有数据只保存在你自己的电脑里。

【需要准备】
1. 安装 Docker Desktop（免费）
   下载: https://www.docker.com/products/docker-desktop/
   Windows 安装后请启动 Docker Desktop，等右下角显示 Running
2. 一个 DeepSeek API Key（大模型接口，按用量付费，价格很低）
   获取: https://platform.deepseek.com/ → API Keys → 创建

【启动步骤（Windows）】
1. 双击 start.bat
2. 首次运行会自动：安装数据库、构建服务（约 5-10 分钟，只需一次）
3. 浏览器会自动打开 http://localhost:3000 ，即可使用

【配置 API Key】
第一次运行前，请编辑本目录下的 .env 文件：
   OPENAI_API_KEY=sk-你的DeepSeek_API_Key
把 sk- 后面的内容换成你自己的 Key，保存即可。
建议同时修改以下登录相关配置：
   AUTH_SECRET=请改成一段随机的长字符串   会话签名密钥，务必修改
   ADMIN_PASSWORD=admin123               首次管理员密码，务必修改

【日常使用】
  启动:     双击 start.bat
  停止:     打开命令行执行  docker compose down
  数据备份: 文档和聊天记录都存在 Docker 数据卷中，
            备份整个项目文件夹即可（含 docker-compose.yml）
  清空数据: docker compose down -v

【登录与账号】
1. 打开系统会自动进入登录页。首次启动默认管理员账号：
     用户名: admin   密码: admin123
   （可在 .env 中用 ADMIN_PASSWORD 修改，见上方"配置 API Key"）
2. 登录后右上角显示当前用户名；需要更多账号时，在登录页点"注册"创建即可。
3. 每个账号的文档、会话、历史数据相互隔离、互不可见，可多人共用。
4. 管理员登录后，导航栏会出现"用户管理"入口，可对普通用户：
     重置密码   删除用户   批量删除用户（勾选多个后一键删除）
   删除用户会级联清除其文档、会话与历史数据，操作前请确认。
   注意：不能删除自己，也不能删除其他管理员账号。

【常见问题】
Q: 提示"未检测到 Docker"？
A: 先安装并启动 Docker Desktop，等显示 Running 后再运行 start.bat。

Q: 提问后报错"证书验证失败 / unable to verify the first certificate"？
A: 你的网络有代理拦截。编辑 .env，取消最后一行注释：
   NODE_TLS_REJECT_UNAUTHORIZED=0
   然后重启服务。

Q: 想换一个端口访问？
A: 编辑 docker-compose.yml，把 "3000:3000" 改成 "8080:3000"，访问 http://localhost:8080

Q: 打开页面自动跳转到登录页，无法直接访问？
A: 正常现象，登录后才能使用（默认 admin / admin123）。注册新账号后需用新账号登录。

【其他系统（Mac / Linux）】
在项目目录打开终端执行：
   cp .env.example .env    # 然后编辑 .env 填入 API Key
   docker compose up -d --build
   # 浏览器打开 http://localhost:3000
